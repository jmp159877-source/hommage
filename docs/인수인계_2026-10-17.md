## 1. 10/17 새벽에 한 일

### 오프닝 고침 2가지 (둘 다 배포됨)
- **'소리 켜고 듣기' 한 번에 재생**: 원인은 목소리 mp3를 jsDelivr에서 먼저 받던 것. 그날 새 파일이 jsDelivr에 몇 시간 늦게 잡혀 첫 누름이 실패하고 두 번째 누름에야 raw로 넘어갔다. 지금은 raw 먼저, 화면이 뜨면 미리 받아 둠(소리는 눌러야만), 실패하면 같은 누름 안에서 jsDelivr로 바꿔 재시도, 누르면 '준비하는 중…' 표시. (js/opening.js)
- **자정~새벽 5시는 '어제 저녁' 인사**: 날짜는 새벽 5시에 바뀐다. 아침 05~10:59, 낮 11~16:59, 저녁 17~04:59.

### 그해 오늘 — '그날의 신문' + '그해, 그곳' (배포됨, 10/17·10/18 하루치 데이터 넣음)
- 화면 순서: 날짜 머리글(○○○○년 10월 17일 ○요일 / 그날의 신문에서) → 한 줄 분위기(mood) → '그날 지면 보기'(동아·경향·한겨레·매경 네이버 뉴스 라이브러리 링크) → 분야별 헤드라인 **정치·경제·사회·문화·연예·생활·스포츠** (확인된 분야만 보이고, 없는 분야는 칸 자체가 안 나옴) → **그해, 그곳 · (지역)** 사진 한 장(실제 연·월·장소·한 줄·출처·원본 링크) → 나는 그때.
- 데이터: `daily/{날짜}.json`(=Firestore daily/{날짜}) 의 `era[ago]` 에 `news:[{field,headline,summary,source_name,source_url}]`, `papers:[[이름,링크]]`, `photo:{area,year,place,caption,src,url,img}`. `news`가 있으면 신문 형식, 없으면 예전 `facts` 형식으로 그대로 보임(js/app.js `eraNewsHtml`).
- 사진은 **place-photos 가지** `out/{지역}-{연도}.jpg` (1200px 이하, 공공누리·CC·퍼블릭 도메인만). 앱은 raw.githubusercontent 로 읽음. 받는 도구: `.github/workflows/place_photos.yml` (workflow_dispatch, 입력 `items` JSON 배열 `[{"name","url"}]` → 받아서 줄여 가지에 올림). 이 환경은 외부 사이트가 막혀 있어 **사진은 반드시 이 워크플로로** 받는다.
- 전국 순서: `data/places.json` (230곳, 서울 25구 → 광역시 구·군 → 세종 → 경기·강원·충북·충남·전북·전남·경북·경남 시·군 → 제주; start 2026-10-17 = 서울 종로구, 10/18 = 서울 중구, 10/19 = 서울 용산구 …).
- 운영자 기준: 사진 연도는 해당 해 앞뒤 **5년까지 괜찮음**, 실제 연·월을 그대로 적는다. 없는 해는 비운다. 틀린 사진·틀린 날짜를 싣느니 비운다.
- 원칙(운영자): 기사 본문 옮기지 않기(제목+두 문장 요약+출처+원문 링크). 요약 말투는 반듯한 '-습니다'체. 연예는 가요·영화·TV·스타, 문화는 책·공연·전시·수상.
- 시험 46가지(그날의 신문: 날짜·분야·연예·사진·나는 그때 추가), 모두 통과 상태.
- 시안: claude.ai 아티팩트 "그해 오늘 신문 시안"(10/17 종로 다섯 해, 글자 크기 보통·큰·최대 단추 있음).

### 자료 찾기에서 알게 된 것 (자동화 설계 근거)
- 이 환경과 하위 조사 에이전트 모두 **newslibrary.naver.com, commons.wikimedia.org, upload.wikimedia.org, photoarchives.seoul.go.kr 접근 불가**. GitHub Actions 안에서는 될 수 있음(미확인).
- 날짜가 확인되는 좋은 출처:
  - 1990년대: **서울신문 지면 기사** `https://www.seoul.co.kr/news/YYYY/MM/DD/YYYYMMDD<면2자리><번호3자리>` (예 19961018005001). 면·번호를 바꿔 가며 읽으면 그날 지면 대부분 확인됨(연예면 15~20은 간혹 안 열림).
  - 2000년대: OSEN(`https://osen.co.kr/article/G0610180001` 꼴, 연예·스포츠), 프레시안, 한국일보, 경기일보, 뉴데일리, 매일신문.
  - 2010년대: 서울신문 m.seoul.co.kr, 경향·스포츠경향, 이투데이, 경북매일(연합 전재), 데일리안, 텐아시아, OSEN.
  - 1970~80년대: 위키백과(한·영)·나무위키 날짜 항목, 노벨재단, 대한체육회 역대 전국체전, SABR(야구), 나무위키 KBS/MBC 연도별 편성(방송일 확인용), KMDb. 얇다. 뉴스 라이브러리가 열려야 채워진다.
  - 사진: **PICRYL(picryl.com)이 위키미디어 공용 미러**로 날짜·장소·라이선스를 보여 주고 cdn2.picryl.com 이미지가 받아진다. Flickr CC(live.staticflickr.com …_b.jpg). 국가기록원 e-영상역사관은 공공누리 4유형(변경 금지)이라 제외.
- 조사 에이전트 한 번에 1년치 8~10건 확인하는 데 5~10분, 사진 한 지역 다섯 해 10~40분. 세션 한도(새벽 4시 초기화)에 걸릴 수 있음.
